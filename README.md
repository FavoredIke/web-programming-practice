# Web Programming Practice

This repository contains my introductory web programming exercises and experiments as I develop my skills in frontend development and version control.

It marks one of my first steps in learning how to build web pages with HTML and manage projects using Git and GitHub.

## Project Overview

The initial project is a simple HTML webpage titled **My First Git Project**.

It introduces a basic webpage structure and displays a short message about my web development journey.

## Concepts Practised

- HTML5 document structure.
- HTML elements such as headings and paragraphs.
- The HTML `<head>` and `<body>` sections.
- Page titles and character encoding.
- Viewport configuration for mobile devices.
- Basic Git and GitHub workflow.

## Technologies Used

- HTML5
- Git
- GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:FavoredIke/web-programming-practice.git
```

### 2. Navigate into the project

```bash
cd web-programming-practice
```

### 3. Open the webpage

Open `index.html` in your preferred web browser or use Visual Studio Code with the Live Server extension.
